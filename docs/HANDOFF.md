# 이음 기획 인계 기록

이 문서는 환경을 옮겨 이음의 공식 기획을 이어갈 때 읽는 현재 상태 기록입니다. 기준일은 **2026년 10월 2일 한국 시간**입니다. 기획의 전체 기준은 [PROJECT_BRIEF.md](PROJECT_BRIEF.md), 자료의 범위와 한계는 [research/README.md](research/README.md)를 참고합니다.

## 저장소와 인계 기준

- 공개 저장소: [shotgun1107/IEUM](https://github.com/shotgun1107/IEUM)
- 브랜치: `main`
- 기획 자료 기준 커밋: `7a8c474fbdb536da78bbc9d352d2b2b2d1a81ee0`
- 해당 기준 커밋은 GitHub `refs/heads/main`에 반영된 것을 확인했습니다.

위 SHA는 기획 자료와 원문을 담은 작업 커밋입니다. 이 인계 문서는 그 이후의 별도 커밋으로 저장합니다. 따라서 최신 커밋과 기준 커밋이 다른 것은 의도된 것이며, 자기 자신의 SHA를 본문에 넣으려고 반복 커밋하지 않습니다. 앞으로 의미 있는 작업을 인계할 때 검증한 작업 커밋과 현재 상태를 갱신합니다.

## 현재 확정 사항

사용자는 이음을 공식 프로젝트로 승격하고 해당 프로젝트의 메인 AI를 공식 총괄로 지정했습니다. 이어받은 대상은 이음의 아이디어와 자료·논의입니다. 이전의 일반 아이디어 정리 프로젝트 운영을 승계한 것은 아닙니다.

현재 이름은 **이음 — AI 중심 프로젝트 지식 관리**로 사용합니다. 이름 재선정부터 다시 시작하지 않습니다. 공개 저장소 이름 `IEUM`과 공개 생성·송신은 사용자가 이번 인계에서 명시적으로 요청했습니다.

현재 단계는 **아이디어를 공식 프로젝트 기획으로 구체화하는 단계**입니다. 전면 구현, 배포와 모든 설계의 확정은 승인된 상태가 아닙니다. 공식 기획을 이어가고 사용자의 결정을 지원합니다.

## 보존한 핵심

목적은 한 프로젝트의 기획·명세·문서를 AI가 정확히 활용하고 변경 이후에도 필요한 기준과 맥락을 유지하는 것입니다. 문서 작성·수정·탐색과 AI 처리의 시간·비용을 줄이려는 의도가 있습니다.

중심 흐름은 다음과 같습니다.

**문서 변경 → 코드·자동화가 의존 관계로 영향 대상 추적 → Jev가 의미적 불일치 판단 → 담당 Luna가 수정 → 검증과 후속 전파**

영향 추적과 Jev의 판단 역할을 바꾸지 않습니다. 모듈의 책임 범위와 관계 자체의 유효성도 검토해야 합니다. 이 구조가 더 단순한 대안보다 정확하고 경제적인지는 아직 검증할 가설입니다.

사용자 확정 의도, 이전 AI의 설계 제안, 외부 자료의 주장, 미정 사항은 기획 기준에서 구분했습니다. 원문의 수치·기술 설명을 이음에서 실행해 검증한 결과로 취급하지 않습니다.

다음 기획 결정은 **누가 어떤 프로젝트에서 어떤 변경 작업에 이음을 처음 사용할지**입니다. 그 결정에 맞춰 첫 대표 작업과 성공·중단 기준을 정합니다. 사용자가 이름 논의나 다른 기획 순서를 요청하면 그 요청을 따릅니다.

미정 사항 전체는 PROJECT_BRIEF.md에 있습니다. 이를 한꺼번에 질문하거나 기술 스택부터 임의로 확정하지 않습니다. 사용자가 이미 제공한 배경을 처음부터 다시 설명하도록 요구하지 않습니다.

## 실제 구현과 환경 상태

현재 저장소에는 문서만 있습니다. Jev·Luna 호출 실험, 의존성 엔진, 검색·검증 엔진, 비용 측정, RRSI 설치·실행·재현은 수행하지 않았습니다. 실행할 앱이나 테스트 스위트, 의존성 명세·잠금 파일도 아직 없습니다.

자료를 읽는 데 별도 런타임과 API 키는 필요하지 않습니다. 복제·동기화에는 Git이 필요합니다. 송신 환경에서 Git `2.54.0.windows.1`, GitHub CLI `2.97.0`과 GitHub 인증을 확인했지만 이 버전을 프로젝트의 필수 요구 버전으로 지정한 것은 아닙니다.

집 PC의 Git 설치, GitHub 쓰기 인증과 개발 환경은 **미확인**입니다. 공개 자료를 복제하는 것과 그 PC에서 개발·모델 호출을 실행할 준비가 된 것은 구분합니다. 집 PC에만 있거나 다른 PC에서 아직 송신하지 않은 작업은 이번 전송 범위가 아닙니다.

## 검증과 보존 범위

- 원문 보고서의 SHA-256이 제공 원본과 일치합니다. 값은 자료 안내에 기록했습니다.
- 게시할 파일의 내용과 크기, 비밀키·토큰·자격 증명 URL·기기별 사용자 경로 패턴을 점검했습니다.
- 작업 커밋의 인덱스 바이트가 검토한 파일 바이트와 일치하는 것을 확인했습니다.
- 새로 작성한 문서의 Git 공백 검사를 통과했습니다. 원문 보고서의 CRLF와 기존 공백은 내용 보존을 위해 변경하지 않았습니다.
- 별도 스태시, 다른 작업 트리의 변경, 실행 중인 Git 병합·리베이스는 발견되지 않았습니다.
- 외부 링크의 현재 상태와 보고서의 모든 인용 수치는 이번 송신에서 재검증하지 않았습니다.

이음의 기획 자료로 확보된 원문은 모두 포함했습니다. 이전 대화 전체, 초기 배경 글의 완전한 별도 파일과 통합 발표문 독립 파일은 확보하지 못했으며, 존재하는 것처럼 재구성하지 않았습니다. 이 자료의 핵심은 전달받은 인계 내용에 근거해 기획 기준과 자료 안내에 정리했습니다.

다른 프로젝트의 운영 파일, 계정 자격 증명과 기기별 상태는 공개 저장소에 포함하지 않았습니다.
