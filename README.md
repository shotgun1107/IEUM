# 이음 — AI 중심 프로젝트 지식 관리

IEUM은 한 프로젝트의 기획·명세·문서를 AI가 정확하게 활용하고, 요구사항 변경 이후에도 관련 지식의 일관성을 유지하도록 돕는 시스템을 구상하는 공식 프로젝트입니다.

현재는 **아이디어를 공식 프로젝트 기획으로 구체화하는 단계**입니다. 실행 가능한 애플리케이션, 모델 호출 실험, 의존성 엔진은 아직 없습니다. 이 저장소는 지금까지의 의도, 핵심 가설, 연구 자료와 미정 사항을 보존합니다.

## 핵심 구상

문서 변경 → 코드가 의존 관계를 따라 영향 대상 추적 → Jev가 의미적 불일치 판단 → 담당 Luna가 수정 → 검증과 후속 전파.

이 역할 조합은 사용자의 중심 가설입니다. 정확도와 전체 비용의 개선은 실제 프로젝트 조건에서 검증해야 합니다. 모듈 경계, 표현 체계, 모델 버전, 호출 정책과 검증 방식은 아직 정해지지 않았습니다.

## 집 PC에서 이어가기

처음 받는 PC에서는 원하는 작업 폴더의 상위 디렉터리에서 다음 명령으로 받습니다. 이미 받은 저장소가 있다면 중복으로 복제하지 말고 기존 폴더의 상태를 확인합니다.

```powershell
git clone https://github.com/shotgun1107/IEUM.git
cd IEUM
```

Codex에서 이 폴더를 열고 다음처럼 요청하면 됩니다.

> AGENTS.md와 docs/HANDOFF.md를 읽고 이음의 공식 프로젝트 기획을 이어가자. 기존 기획과 원문 자료에서 사용자 의도, AI 제안, 외부 주장과 미정 사항을 구분하고, 다음 결정부터 진행해.

현재 자료를 읽는 데는 별도 런타임이나 API 키가 필요하지 않습니다. Git은 복제와 이후 동기화에 필요합니다. 집 PC의 설치·인증 상태는 확인하지 않았습니다.

## 현재 결정 상태

- 이음의 공식 프로젝트 승격과 메인 AI의 공식 총괄 역할은 확정되었습니다.
- 현재 이름은 **이음 — AI 중심 프로젝트 지식 관리**, 저장소 이름은 **IEUM**입니다. 상표·도메인 사용 가능성은 조사하지 않았습니다.
- 저장소는 사용자의 요청으로 공개합니다. 공개 저장소 생성은 모든 설계의 확정이나 즉시 구현을 뜻하지 않습니다.
- 첫 적용 대상과 MVP, 성공·중단 기준을 정하는 기획이 남아 있습니다.

연구 보고서와 이전 논의는 설계의 참고 자료입니다. 보고서에 인용된 결과를 이 시스템에서 검증한 성능으로 제시하지 않습니다.
